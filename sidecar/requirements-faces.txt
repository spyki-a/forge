# The face finder — optional (docs/CLIPS.md §4.3, vision.faces).
#
# MediaPipe's face detector, BlazeFace full range, run in a child process
# (forge_sidecar/workers/mp_faces.py). Two files, installed in two pip runs,
# because pip rejects --no-deps inside a requirements file:
#
#   pip install -r sidecar/requirements-faces.txt
#   pip install --no-deps -r sidecar/requirements-faces-nodeps.txt
#
# This first file is what mediapipe 0.10.35 needs at runtime, pinned to the
# versions that ran on CPython 3.14.6 — pinned here because the second run's
# --no-deps checks none of mediapipe's own ranges (absl-py~=2.3,
# sounddevice~=0.5, flatbuffers~=25.9). numpy comes from requirements.txt.
#
# What --no-deps leaves out is opencv-contrib-python and matplotlib, ~65 MB
# that detection never uses. mediapipe still imports them at import time
# (drawing_utils.py:20-21), so the worker runs with three empty stub files
# first on ITS PYTHONPATH (forge_sidecar/stubs) — never the helper's, so a
# real cv2 installed later is not shadowed there.
#
# The model, blaze_face_full_range.tflite (1,083,786 B), is not installed
# here: it is fetched from storage.googleapis.com on the press of the button
# that names its size (vision.facesModel with download: true).
